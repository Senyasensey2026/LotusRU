# Lotus RU

Версия перевода совпадает с версией Lotus, под которую он сделан: **Lotus RU 1.8.1 → Lotus 1.8.1**.

Русский перевод для мода-торговца **Lotus** (SPT 4.1.x).
Устанавливается отдельно и не изменяет файлы оригинального мода.

## Что переведено
- все задания Лотос: названия, описания, цели, сообщения о выполнении и провале, реплики игрока;
- имя торговца, его описание и местоположение;
- ключ-карта Лотос;
- диалоги с водителем БТР из сюжетной линии мода.

## Требования
- SPT 4.1.6+
- [Lotus](https://sp-mod.com/) 1.8.1
- WTT-CommonLib (нужен для самого Lotus)

## Установка
1. Распакуйте архив в корневую папку SPT (туда, где лежит `SPT.Server.exe`).
2. Проверьте, что появилась папка `SPT/user/mods/LotusRU`.
3. Если раньше стоял старый перевод, заменявший `Lotus/db/CustomQuests/.../Locales/ru.json`, удалите этот файл (или переустановите Lotus).
4. Запустите сервер. В логе должна появиться строка `[Lotus RU] Loaded ...`.
5. Язык игры — русский.

## Удаление
Удалите папку `SPT/user/mods/LotusRU`.

## Сборка из исходников
Нужен .NET 10 SDK.
```
dotnet build -c Release
```
Готовый мод появится в `bin/Release/LotusRU` (`LotusRU.dll` + папка `locales`).

## Как это работает
DLL загружается после Lotus и WTT-CommonLib (`PostLoad + 10`) и:
- добавляет трансформер к русской локали, который записывает тексты из `locales/ru.json`;
- добавляет язык `ru` в диалоги Lotus из `locales/dialogues_ru.json`.

Тексты лежат в обычных JSON-файлах, их можно править без пересборки.
